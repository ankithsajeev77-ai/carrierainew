About

How it works and what is not included.

Scoring. Skills 50% (rarer skills weigh more), title 20%, experience 12%, work mode 9%, salary 9%. Resume ATS score: 50% skill match, 25% keyword match, 25% format checks.

AI features. Roadmaps, mock interviews, career chat and resume suggestions all have built-in guidance that works in a regular browser. Claude generates enhanced responses when its AI service is available. A real generative AI service for a standalone site needs a secure server connection; an API key must never be placed in this HTML file.

Not included. Real login and password reset, email alerts and an admin dashboard (these need a secure backend), and verified salary data (needs a licensed API). Your data is saved to your claude.ai account or this browser, so there is no separate login.

Data. Current listings are fetched from the public Arbeitnow and RemoteOK job feeds, matched against your target role and skills, and linked to the source posting. Availability depends on each provider’s feed.
